## General rules
- **Framework:** Use Python's built-in `unittest` module (`unittest.TestCase`).
- **Running Tests:** Run test files using `make test`.
- **Reformatting:** The command to reformat code is `make fmt`.
- **Makefile** This project has a Makefile which shows how to run other commands.
- **Poetry:** This project uses Poetry for example `poetry@2.2.1 run python -m unittest discover . -v`.
- **Coverage:** Every new feature, bug fix, or refactor must include corresponding `unittest` coverage.
